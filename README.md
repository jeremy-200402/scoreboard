# Scoreboard

面向麻将、扑克等线下牌局的移动端优先零和计分 Demo。一次操作由一名给分人向一名或多名接收人分别给分，系统自动计算给分人的扣分并保存可追溯流水。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可体验。

## 验证

```bash
npm test
npm run build
```

## MVP 能力

- 创建 2 至 8 人房间，所有玩家从 0 分开始
- 一对一或一对多批量给分，实时计算总扣分
- 自动维持房间总分为 0
- 查看、修改和撤销历史给分流水
- 结束房间并查看最终排名
- 使用 IndexedDB 保存本地数据，刷新后可继续
